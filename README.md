# 免费体验：客户临时加需求，怎么把范围说清楚？

原本说好做三页静态网站，客户又想“顺便”加会员、预约和付款，还希望按原日期上线。你会怎样回应？

这里提供一轮免费的虚构案例练习。你的AI助手扮演客户，等待你自己回答，再引用你的实际原句，帮你观察两件事：有没有分清原范围与新增要求；有没有保留交期、报价和可行性的未知。

**无需购买，不需要真实客户资料，也没有自动付款。** 适合已经能使用带本地工具的AI助手的成人网页接单新手。它是练习材料，不是法律意见、真实项目报价、职业认证或赚钱保证。

## 三步开始

1. 点击本仓库上方 **Code → Download ZIP**，解压下载文件。
2. 把其中的 `scope-clarify-preview` 文件夹交给能读取本地文件、运行Python的AI助手。让助手读取里面的 `SKILL.md`。
3. 对助手说：

   > 体验一次范围澄清。请使用这个文件夹里的免费样例，不要替我回答。

之后直接用中文回复即可。你不需要改JSON、写提示词配置或自己输入终端命令。需要操作文件时，由你的AI助手在你允许的目录内完成。把个人练习记录放在仓库之外的独立文件夹，避免日后公开提交自己的回答。

## 使用前看一眼

- 需要你自己的AI助手和模型权限/额度，以及本地文件读写、Python 3.9+执行能力。本包不包含模型服务。
- 普通ChatGPT网页或手机聊天，如果没有本地文件和执行工具，不能按本样例实现可靠保存；不要把“助手说记住了”当作已经落盘。
- 脚本只保存原句和阶段，不会生成你的回复，也不会自动理解语义。角色答复和反馈由你选择的AI服务完成，仍可能出错。
- 脚本本身不联网；你与AI的对话如何处理，取决于你使用的AI服务及其设置。请始终使用虚构案例，不提供客户资料或秘密。
- 单轮回复及反馈可以在同一个本地目录恢复；不提供跨设备自动同步。
