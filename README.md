# 免费体验：客户临时加需求，怎么把范围说清楚？

原本说好做三页静态网站，客户又想“顺便”加会员、预约和付款，还希望按原日期上线。你会怎样回应？

这里提供一个固定虚构案例的一轮免费练习。你的AI助手扮演客户，等待你自己回答，再引用你的实际原句，帮你观察两件事：有没有分清原范围与新增要求；有没有保留交期、报价和可行性的未知。

**无需购买，不需要真实客户资料，也没有自动付款。** 可以先复制下面的文字，在你已有的AI对话里试一轮；需要本地保存和恢复时，再下载免费Skill。两种方式都需要你自己的AI服务权限和额度，不包含模型服务。这个练习不是法律意见、真实项目报价、职业认证或赚钱保证。

## 方式一：不下载，先聊天试一轮

把下面这段复制给你自己的AI，然后自己用中文回应客户：

```text
扮演虚构陶艺工作室客户。原项目为3页静态网站，只展示文图和联系信息，不含登录、预约或支付；含1轮文案、图片和样式修改，资料齐备起5天交付，目前第3天，原日历日期未核，虚构费用2400元。你现在提出：能不能顺便加会员登录、自助预约和在线付款，周五宣传时上线，并算在原修改内？
先等我回复，不要替我回答。收到后引用我的原句，指出一项已经澄清的边界和一项仍需确认的问题。不要把周五当成已核合同日期，不打总分，不声称已保存进度。
```

这是单轮聊天风格预览。它不安装Skill、不保存本地记录，也不验证本地恢复；AI的实际表现取决于你使用的服务，未逐一验证所有客户端。请只用虚构案例，AI反馈可能出错。

## 方式二：下载本地免费Skill

适合已经能使用带本地工具AI助手的成人网页接单新手：

1. 点击本仓库上方 **Code → Download ZIP**，解压下载文件。
2. 把其中的 `scope-clarify-preview` 文件夹交给能读取本地文件、运行Python的AI助手。让助手读取里面的 `SKILL.md`。
3. 对助手说：

   > 体验一次范围澄清。请使用这个文件夹里的免费样例，不要替我回答。

之后直接用中文回复即可。你不需要改JSON、写提示词配置或自己输入终端命令。需要操作文件时，由你的AI助手在你允许的目录内完成。把个人练习记录放在仓库之外的独立文件夹，避免日后公开提交自己的回答。

本地Skill使用前请核对：

- 需要本地文件读写、Python 3.9+执行能力和你自己的模型权限/额度。本包不包含模型服务。
- 普通ChatGPT网页或手机聊天，如果没有本地文件和执行工具，不能实现这份本地Skill的可靠保存；不要把“助手说记住了”当作已经落盘。
- 脚本只保存原句和阶段，不会生成你的回复，也不会自动理解语义。角色答复和反馈由你选择的AI服务完成，仍可能出错。
- 脚本本身不联网；你与AI的对话如何处理，取决于你使用的AI服务及其设置。请始终使用虚构案例，不提供客户资料或秘密。
- 单轮回复及反馈可以在同一个本地目录恢复；不提供跨设备自动同步。
